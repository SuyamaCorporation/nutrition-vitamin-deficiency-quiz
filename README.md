# 栄養素・ビタミン欠乏症リスク診断クイズ

食習慣・症状に関する診断クイズに答えてビタミン・ミネラル欠乏リスクを評価するツール。

## 機能

- 20問の診断質問（食習慣・症状・ライフスタイル）を2択/3択/4択で出題
- ビタミンD・B12・鉄・亜鉛・マグネシウム・葉酸の6栄養素ごとのリスクスコア算出
- リスクレベル（高/中/低）を棒グラフで表示
- 高リスク栄養素の役割・欠乏症状・多い食材の解説カード自動表示
- 医療機関受診推奨の注意書き付き

## 技術仕様

- バニラJS / Tailwind CDN
- XSSガード実装済み（escHtml関数）
- レスポンシブ対応
- 全インタラクティブ要素にaria-label付与
